# Psychosis Polyrisk Score (PPS)

This repository contains analytic code for the external validation, model development, and internal validation of the Psychosis Polyrisk Score (PPS).

The scripts include:
- external validation of the original PPS model;
- model development and internal validation using the expanded AMP SCZ predictor set;
- model development and internal validation using the original EU-GEI predictor set.

No individual-level AMP SCZ or EU-GEI data are included in this repository.
